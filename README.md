# SecurE-Commerce
MVP de uma plataforma B2B de monitoramento e gerenciamento de riscos para varejos e e-commerce.

SecurE-Commerce é uma plataforma B2B de monitoramento e gerenciamento de riscos para varejo e e-commerce. O protótipo centraliza eventos de PDVs, APIs e canais digitais, utilizando um Risk Engine para identificar anomalias, calcular riscos e priorizar incidentes, oferecendo uma visão unificada para apoiar decisões rápidas e reduzir impactos de segurança e operação.
Tecnologias atuais:

HTML5
CSS3
JavaScript

Próxima etapa:

Java
Spring Boot
PostgreSQL
API REST
Autenticação JWT
Risk Engine
Integrações com APIs e sistemas internos
