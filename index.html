GETTING STARTED

Integre em minutos

O SecurE-Commerce recebe eventos de segurança por REST API. O Event Engine normaliza os dados e o Risk Engine atribui um score de risco.

1. Crie uma API Key

Na página de API, crie uma credencial específica para o seu ambiente.

2. Envie eventos

curl -X POST https://api.securE.local/api/v1/events \
-H "Authorization: Bearer sr_live_YOUR_KEY" \
-H "Content-Type: application/json" \
-d '{"type":"LOGIN_FAILED","source":"ecommerce"}'

3. Consulte os incidentes

Eventos de alta confiança podem gerar incidentes automaticamente. Use os endpoints de incidentes para acompanhar investigação e resolução.

ℹ️ Segurança: nunca exponha uma API Key no frontend do seu e-commerce.
